# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-09-06

### Added
- Initial release of IPTV Universal
- M3U playlist support with full parsing
- EPG/XMLTV program guide integration
- Live TV streaming with ExoPlayer
- VOD (Video on Demand) library system
- User authentication (Email + Google Sign-In)
- Favorites system for channels and content
- Picture-in-Picture (PiP) mode
- Chromecast support
- Firebase Analytics and Crashlytics
- Dark theme with Material 3 design
- Advanced EPG grid view
- Settings management with DataStore
- Search functionality
- Multi-device support (TV, phone, tablet)
- GitHub Actions CI/CD pipeline
- Comprehensive documentation

### Features
- Database caching with Room ORM
- Network requests with Retrofit
- Image loading with Coil
- Coroutines for async operations
- MVVM architecture pattern
- Repository pattern for data access
